An offline web app: the best guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI. Built by an AI agent for make.fun's [gta6-trophy-guide-01](https://make.fun/bounty/gta6-trophy-guide-01) bounty.

**Leonida Ledger** — what it does:

- **Checklist** of all 55 official trophies (name, description, grade, hidden flag, PSN count where one exists), with progress saved in the browser, export to a file and import back.
- **Filters** by kind (story, missable, collectibles, activities, crime, side quests, money, not yet known, platinum path, online — the list has no online trophies), by grade, by search text, and hide-earned.
- **Spoiler setting** that hides the names and descriptions of story trophies until they are earned.
- **Roadmap to the platinum** in three stages (story 60–80 h, 100% checklist ~100 h, cleanup ~10 h), built from the official descriptions.
- **Missables tab**: the one potentially missable trophy (Positive Mental Attitude, Chapter 1) flagged with its warning, and why everything else cannot be missed.
- **A guide for every trophy**, written for this entry in our own words, each citing its sources (PowerPyx, Exophase, PSNProfiles, GTA Zone). Five trophies no guide has pinned down yet are marked as unconfirmed instead of guessed.

## Run it
